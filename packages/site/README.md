# @dropvid/site

DropVid 官网营销包：首页、定价页及全部落地页组件。

## 结构

```
src/
  pages/         Home、Pricing
  components/    Hero、下载区、平台列表等
  api/           平台/限额/更新 manifest
  config/        下载与定价配置
  hooks/
  utils/
  assets/
  styles/
```

## 依赖

- `@dropvid/shared` — API、类型、fetchJson
- `@dropvid/ui` — Icon
- `@dropvid/account` — SiteHeader 登录态
